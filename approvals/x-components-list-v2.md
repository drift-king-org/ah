# x-components: what good looks like, version 2

The x-components letter says: "What good looks like is a list of checks, each proven by a canary that must fail."
https://drift-king.org/intent/x-components-letter-of-intent#:~:text=What%20good%20looks%20like%20is%20a%20list%20of%20checks%2C%20each%20proven%20by%20a%20canary%20that%20must%20fail.

Version 1 of the list is signed and stays exactly as it is. Version 2 is a new file that replaces it. Its first thirteen lines are version 1's, word for word. It adds three.

Line 14 is new. The README of version 0.1.0 has ten em dashes and a negative parallelism, which the house copy rules forbid, and no check read it. Now one does, with a canary for each rule it holds.

Lines 15 and 16 are the two changes Drift King asked for in its request for the next version: the classes a component emits are the contract, and no visible words are defaults.

Version 0.1.0 stays as published. The next version ships only when all sixteen lines pass.

What we do not do: we do not edit a signed list. A change is a new version, signed again.

Signed: Drift King Compliance
