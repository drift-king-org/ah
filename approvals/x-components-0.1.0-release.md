https://drift-king.org/intent/x-components-letter-of-intent#:~:text=A%20release%20ships%20only%20when%20every%20check%20passes%20on%20the%20exact%20bytes%20it%20ships.

https://github.com/Apricotter/x-components/commit/b1a6b38e4e0edabe68a1e8972eb641095a04440f

This document's approval page lists the eight files npm will publish from that commit, the checks Drift King ran on them, and what each check found, with the fingerprint of every file. Anyone can fetch the same commit, run the same checks, and get the same page.
https://drift-king.org/approvals/x-components-0.1.0-release-approval

This approves tagging v0.1.0. It does not approve taking the version into Drift King: that is signed once the published tarball is checked against these files.

What we do not do: we do not count a check that has not run as passed.
