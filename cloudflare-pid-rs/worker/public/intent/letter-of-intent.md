# Drift King: letter of intent

We build Drift King to stop drift. Nothing is built or run unless the model names it.

Intent comes first. We write what we intend in plain language, and we sign it. Behavior, tests, code and the model are projections of that intent. Each one is checked against it.

The model is the only place facts live: ah.ttl, and the not-ah.ttl it requires. When anything disagrees with the model, it does not ship.

Every change is signed and hashed. The hash goes on a public log we cannot edit, starting with Rekor.

We keep it small. If the model does not need it, we do not add it.

What we do not do: we do not edit a signed intent. A new intent is a new letter, signed again.

Signed: Lead Architect, Drift King
